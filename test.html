AP CSP Unit 3 Practice Test

Intro to App Design: Lessons 1, 2, 5, 6 (Apps, Design Mode, Intro to Programming, Debugging) + the Unit 3 App Project (Planning Guide, Digital Notebook) + Unit 3 vocab. Code.org assessment difficulty: code tracing, bug diagnosis, scenarios, with no easy-to-eliminate answer choices.

How it works

  • Questions are pulled randomly from a bank of questions, so every attempt is different.
  • Includes questions in the exact Code.org Unit 3 assessment format (the Quizlet set): "the following program is run, then the user clicks topButton ONCE, what is displayed in the console", "which line is MOST likely to result in an error", "which BEST describes", "which is NOT a reason".
  • Every answer choice is written to be plausible. Expect to read each option carefully; the questions are modeled on the Code.org Unit 3 assessment wording.
  • Mix matches the real quiz: about 50% code reading (trace a program, identify what each part does), 25% vocabulary, 25% development process ("here is what someone is doing, which stage/term is it"). Mostly multiple choice, some multi-select, a little true/false.
  • Timer runs the whole time. When it hits 0:00 the test auto-submits.
  • You cannot go back. Once you lock in an answer, you move forward only.
  • Multi-select is all-or-nothing, like a Canvas "choose all that apply."
  • Answers and explanations appear only after you submit. Anything you miss is saved to the Missed Questions tab so you can retake it later.
Progress through the bank

New tests pull unseen questions first, so you will not get repeats until you have seen everything.

Works fully offline. Your missed and seen questions are saved in this browser.
