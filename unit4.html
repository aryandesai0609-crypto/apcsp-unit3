AP CSP Unit 4 Practice Test

Unit 4: Variables, Conditionals, and Functions (Lessons 1-11 + Unit 4 vocab). AP exam pseudocode and JavaScript code tracing, with no easy-to-eliminate answer choices.

How it works

  • Questions are pulled randomly from a bank of questions, so every attempt is different.
  • Every answer choice is written to be plausible. Expect to read each option carefully; the questions are modeled on the Code.org and AP CSP assessment wording, including AP exam pseudocode.
  • Mix: about 60% code tracing (variables, expressions, modulus, Booleans, if/else-if, functions, AP pseudocode), 20% vocabulary, 20% concepts. Mostly multiple choice, a few multi-select and true/false.
  • Timer runs the whole time. When it hits 0:00 the test auto-submits.
  • You cannot go back. Once you lock in an answer, you move forward only.
  • Multi-select is all-or-nothing, like a Canvas "choose all that apply."
  • Answers and explanations appear only after you submit. Anything you miss is saved to the Missed Questions tab so you can retake it later.
Progress through the bank

New tests pull unseen questions first, so you will not get repeats until you have seen everything.

Works fully offline. Your missed and seen questions are saved in this browser.
